History of the Web

I. Introduction

The World Wide Web is a global information system that users can access via any device connected to the internet. Tim Berners-Lee, a British scientist, invented the World Wide Web (WWW) in 1989, while working at CERN.

The Web was originally conceived and developed to meet the demand for automated information-sharing between scientists in universities and institutes around the world. It is based on technologies such as HTML, HTTP, and URLs.

  • Wikipedia - History of the World Wide Web

II. Milestone Timeline

1989 — The Web is Proposed

Tim Berners-Lee first came up with the idea for the World Wide Web. He saw that millions of computers were being connected through the fast-developing internet, and he realized they could share information by using an emerging technology called hypertext.

To present his idea, he wrote the first proposal in March 1989, which became the foundation of the World Wide Web.

Why it mattered

It was the beginning of the idea that became the World Wide Web.

Sources

  • CERN - A Short History of the Web
  • World Wide Web Foundation - History of the Web
  • The History of the Web - Timeline

1990–1993 — The First Web Browser and Web Server

Tim Berners-Lee wrote the first web page editor and browser, called "WorldWideWeb.app", and the first web server, called "httpd", in 1990.

The web page was served on the open internet and featured a built-in HTML editor along with graphical features. In 1991, people outside of CERN were invited to join this new web community.

As the Web began to grow, Tim Berners-Lee realized that its true potential would only be achieved if anyone, anywhere could use it without paying a fee or asking for permission.

Why it mattered

The Web changed from an idea into a working system and began spreading beyond CERN. It could now be developed and used by people around the world.

Sources

  • The History of the Web - Timeline
  • World Wide Web Foundation - History of the Web

1993 — Mosaic Web Browser

Early in 1993, the National Center for Supercomputing Applications (NCSA) at the University of Illinois released the first version of its Mosaic browser.

It was developed by Marc Andreessen and Eric Bina. Mosaic included inline multimedia, an easy-to-use graphical user interface, and visual elements that web designers could use.

NCSA's Mosaic became the world's first popular graphical internet browser.

Why it mattered

It helped move the Web from a technology mainly used by researchers toward something accessible to ordinary computer users.

Sources

  • NCSA - History
  • The History of the Web - Timeline
  • CERN - A Short History of the Web

1994–1996 — W3C is Created and CSS is Introduced

In October 1994, Sir Tim Berners-Lee founded the World Wide Web Consortium (W3C) at the Massachusetts Institute of Technology Laboratory for Computer Science (MIT/LCS), in collaboration with CERN.

Håkon W. Lie proposed the first version of Cascading Style Sheets (CSS) as a way of styling Web pages. CSS was later adopted by the W3C as an official standard and gradually integrated into modern browsers.

Why it mattered

Web standards helped different browsers, computers, and websites work together more consistently. CSS made Web pages easier to design, maintain, and format consistently.

Source

  • The History of the Web - Timeline

1997 — HTML 3.2

After HTML 3.0 was officially abandoned, the W3C drafted and published HTML 3.2 as an official recommendation.

The new specification included several features that were already implemented in browsers, such as tables, superscripts, advanced forms, and more.

Why it mattered

HTML 3.2 helped establish common features and standards for Web pages across different browsers.

Source

  • The History of the Web - Timeline

2004 — WHATWG is Created

The Web Hypertext Application Technology Working Group (WHATWG) is a community of people interested in evolving the Web through standards and tests.

WHATWG was founded by individuals from Apple, the Mozilla Foundation, and Opera Software in 2004, after a W3C workshop.

The WHATWG focuses on standards that can be implemented in web browsers and their associated tests.

Why it mattered

Its work became an important part of the development of modern HTML and Web applications.

Source

  • WHATWG - FAQ

2007–2014 — HTML5 Development and W3C Recommendation

HTML5 added new syntactic elements and attributes, deeper APIs, and more access to native features. It also provided broader support for multimedia and Web graphics with elements such as <video> and <canvas>.

HTML5 was formally made a recommendation by the W3C.

Why it mattered

HTML5 provided a modern standardized foundation for creating Web pages and Web applications.

III. 3 Key Technologies of the Web

1. HTML — HyperText Markup Language

HTML is the standard markup language for creating Web pages. It describes the structure of a Web page and consists of elements such as headings, paragraphs, and links.

Source: W3Schools - HTML Introduction

2. HTTP — HyperText Transfer Protocol

HTTP is a communication protocol used between client computers, such as Web browsers, and Web servers. Communication is done by sending HTTP requests and receiving HTTP responses.

Source: W3Schools - What is HTTP?

3. URL — Web Resource Identification

A URL (Uniform Resource Locator) is the address of a resource on the Web. It is one of the key mechanisms used by browsers to retrieve published resources, such as HTML pages, CSS documents, images, and more.

Source: MDN Web Docs - What is a URL?
