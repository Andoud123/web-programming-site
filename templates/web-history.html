I- Introduction

The World Wide Web is a global information that users can access via any device connected to the internet. Tim Berners-Lee, a British scientist, invented the World Wide Web (WWW) in 1989, while working at CERN. The web was originally conceived and developed to meet the demand for automated information-sharing between scientists in universities and institutes around the world. It’s based on technologies such as HTML, HTTP, and URLs.

Sources:
  • CERN - The Birth of the Web
  • Wikipedia - History of the World Wide Web

II- Milestone Timeline

1989 — The Web is proposed

Tim Berners-Lee first comes up with the idea for the World Wide Web and saw that millions of computers were being connected through the fast-developing internet, then he realized they could share information by exploiting an emerging technology called hypertext. To pitch it, he wrote the first proposal in March 1989, that became the foundation of the World Wide Web.

Why it mattered: It was the beginning of the idea that became the World Wide Web.

Sources:

  • CERN - Short History of the Web
  • Web Foundation - History of the Web
  • The History of the Web - Timeline

1990 - 1993 — The first Web Browser and Web Server

Tim wrote the first web page editor/browser (“WorldWideWeb.app”) and the first web server (“httpd“) in 1990. The web page was served on the open internet, featuring a built-in HTML editor alongside graphical features, and in 1991, people outside of CERN were invited to join this new web community. As the web began to grow, Tim realised that its true potential would only be unleashed if anyone, anywhere could use it without paying a fee or having to ask for permission.

Why it mattered: The Web changed from an idea into a working system and began spreading beyond CERN and could be developed and used by people around the world.

Sources:

  • The History of the Web - Timeline
  • Web Foundation - History of the Web

1993 — Mosaic Web browser

Early in 1993, the National Center for Supercomputing Applications (NCSA) at the University of Illinois released a first version of its Mosaic browser. It was developed by Marc Andreessen and Eric Bina, and features inline multimedia, an easy-to-use GUI, and visual elements for web designers to make use of. NCSA’s Mosaic became the world’s first popular graphical internet browser.

Why it mattered: It helped move the Web from a technology mainly used by researchers toward something accessible to ordinary computer users.

Sources:

  • NCSA - History of NCSA
  • The History of the Web - Timeline
  • CERN - Short History of the Web

1994 -1996 — W3C is created and CSS is introduced

In October 1994, Sir Tim Berners-Lee founded the World Wide Web Consortium (W3C) at the Massachusetts Institute of Technology, Laboratory for Computer Science [MIT/LCS] in collaboration with CERN. Håkon W. Lie proposes the first iteration of Cascading Style Sheets, or CSS, as a way of styling web pages and it is adopted by the W3C as an official standard, and is integrated into modern browsers little by little.

Why it mattered: Web standards helped different browsers, computers, and websites work together more consistently. CSS made Web pages easier to design, maintain, and format consistently.

Source: The History of the Web - Timeline

1997 — HTML 3.2

After HTML 3.0 is officially abandoned, the W3C drafts and publishes HTML 3.2 as an official recommendation. The new specification includes several features already implemented in browsers such as tables, superscripts, advanced forms, and more. Much of this version of HTML is still in use today.

Source: The History of the Web - Timeline

2004 — WHATWG is created

The Web Hypertext Application Technology Working Group (WHATWG) is a community of people interested in evolving the web through standards and tests. The WHATWG was founded by individuals of Apple, the Mozilla Foundation, and Opera Software in 2004, after a W3C workshop. The WHATWG’s focus is on standards implementable in web browsers, and their associated tests.

Why it mattered: Its work became an important part of the development of modern HTML and Web applications.

Source: WHATWG FAQ

2007-2014 — HTML5 development and W3C Recommendation

HTML5 adds new syntactic elements and attributes, deeper APIs, and more access to native features. It also includes much broader support for multimedia and web graphics with elements like video and canvas. HTML5 is formally made a recommendation by W3C.

Why it mattered: HTML5 provided a modern standardized foundation for creating Web pages and Web applications.

Source: The History of the Web - Timeline

III- 3 Key Technologies of the Web

1. HTML — HyperText Markup Language

HTML is the standard markup language for creating Web pages. It describes the structure of a Web page and consists of a series of elements such as heading, paragraph, link, etc.

Source: W3Schools - HTML Introduction

2. HTTP — HyperText Transfer Protocol

Communication protocol between Client Computers (Web Browsers) and Web Servers is done by sending HTTP Requests and receiving HTTP Responses.

Source: W3Schools - HTTP Introduction

3. URL — Web Resource Identification

A URL (Uniform Resource Locator) is the address of a unique resource on the internet. It is one of the key mechanisms used by browsers to retrieve published resources, such as HTML pages, CSS documents, images, and so on. In theory, each valid URL points to a unique resource.

Source: MDN - What is a URL?
